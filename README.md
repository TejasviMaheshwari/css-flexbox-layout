# CSS Flexbox Layout

## 📌 About the Project

This project demonstrates the use of **CSS Flexbox** to create a structured web page layout using HTML and CSS. It contains a header, footer, middle section, sidebar, and nested content areas.

## ✨ Features

* Header and footer sections
* Middle section with left and right areas
* Nested top and bottom sections
* Flexbox-based horizontal layouts
* Different background colors for visual distinction
* CSS box-sizing, margin, and padding reset

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox

## 📂 Project Structure

```text
css-flexbox-layout/
├── index.html
└── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation or setup is required.

## 🎯 Learning Objectives

* Understand the basics of CSS Flexbox.
* Create horizontal layouts using `display: flex`.
* Organize a web page into multiple sections.
* Apply CSS properties such as `width`, `height`, `background-color`, and `box-sizing`.
